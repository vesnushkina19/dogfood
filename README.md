# DogFood

DogFood — учебный интернет-магазин товаров для собак на React.

## Функциональность:

- просмотр каталога товаров
- поиск товаров по названию
- просмотр страницы товара
- добавление товаров в корзину
- отображение количества товаров на иконке корзины
- корзина доступна без регистрации
- товары в корзине сохраняются после регистрации
- локальная регистрация и вход через localStorage
- админская очистка локальных регистраций
- добавление товара через форму
- избранное для авторизованных пользователей

## Стек:

- React
- React Router
- React Bootstrap
- Webpack
- Yarn
- localStorage

## Запуск проекта

Установить зависимости:
yarn install

Запустить проект:
yarn start
